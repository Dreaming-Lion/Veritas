# 사용자 효과 측정 초안 (실측 전)

## 로그로 측정 (서버에 이벤트 저장 필요)
- 반대 관점 추천 영역 노출 수 / 클릭 수 → **반대 관점 기사 클릭률(CTR)**
- 기사 상세 진입 1회당 추천 기사 클릭 수
- 법안·브리핑 원문 링크 클릭률
- 북마크 전환율

## 설문 (5점 척도)
1. 추천된 반대 관점 기사가 방금 읽은 기사와 같은 이슈를 다룬다.
2. 추천 기사를 읽고 같은 사안을 다른 시각에서 볼 수 있었다.
3. 법안·브리핑 원문 제공이 판단에 도움이 되었다.
4. 추천이 나오기까지의 대기 시간이 적절했다.
5. 이 서비스를 계속 이용하고 싶다.
6. (주관식) 가장 도움이 된 점 / 불편했던 점

## 권장
- 최소 20명 이상 참여, 정치 성향 자가 응답 포함 (성향별 만족도 비교).
- 수치는 실제 응답으로만 기재하세요.
